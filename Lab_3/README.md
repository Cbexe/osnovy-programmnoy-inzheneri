## Практическая работа №3. Условные операторы

### Цель работы
Изучение условных операторов Python и применение логических выражений для реализации алгоритмов ветвления.

### Выполненные задания

**A1. Координатные четверти**

Программа получает координаты двух точек на плоскости и определяет, находятся ли они в одной координатной четверти. Если находятся, выводит номер четверти.

**A2. Проверка надёжности пароля**

Программа проверяет пароль на соответствие требованиям:
- Длина — ровно 8 символов.
- Наличие заглавных и строчных букв.
- Наличие цифр.
- Наличие специальных символов `*`, `-`, `#`.
- Отсутствие недопустимых символов.

Программа выводит все обнаруженные ошибки или сообщение «Надежный пароль».

**A3. Расчёт стоимости газа**

Программа получает предыдущие и текущие показания газового счётчика, рассчитывает объём использованного газа, сумму оплаты и среднюю стоимость одного кубометра.

### Структура папки

```text
Lab_3/

```

### Инструкция по запуску

Для запуска программ необходимо:
1. Установить Python 3.
2. Открыть папку Lab_3 в Visual Studio Code.
3. Открыть нужный файл A1.py, A2.py или A3.py.
4. Запустить программу кнопкой Run Python File.
5. Ввести необходимые исходные данные в терминале.

- Операции сравнения
- Работа со строками
- Модуль string
