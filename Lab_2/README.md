# Основы программной инженерии

Репозиторий содержит решения практических работ по дисциплине «Основы программной инженерии».

## Практическая работа № 2

Папка: `Lab_2`

### Выполненные задания

- **A4.py** — нахождение большего из двух целых чисел.
- **A5.py** — проверка, делится ли число A на число B нацело.
- **A6.py** — перевод количества секунд в часы, минуты и секунды.
- **A7.py** — определение цвета шахматных клеток.

## Как запустить программы

Для запуска необходим установленный Python 3.

1. Откройте терминал в папке `Lab_2`.
2. Выполните команду для нужного задания:

   `python A4.py`

   Вместо `A4.py` можно указать `A5.py`, `A6.py` или `A7.py`.

3. Введите запрашиваемые программой данные.

Каждое задание запускается отдельно.
